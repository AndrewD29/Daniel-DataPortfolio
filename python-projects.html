Postcode Lookup Automation

Python Pandas API Integration Data Engineering

Situation

Operational datasets frequently contained latitude and longitude coordinates but required postcode data for reporting, mapping and geographic analysis. Looking up large volumes of records manually was slow, repetitive and prone to error.

Task

Create an automated process capable of enriching thousands of records with postcode information and exporting the results directly back into Excel.

Action

Developed a Python solution using Pandas and the Postcodes.io API to process coordinate data in bulk. The script imported Excel files, submitted requests automatically, tracked progress and returned postcode information for each location. 

df['Postcode'], df['Status'] = get_batch_postcodes(df)

df.to_excel(
    "bulk_postcode_results.xlsx",
    index=False
)

Result

100% Automated process
Minutes Instead of hours
Reusable For future datasets

The solution removed a manual data enrichment task, improved consistency of location-based reporting and enabled postcode-level analysis across operational datasets.

Power BI Documentation Generator

Python Power BI PBIXRay Data Governance

Situation

Power BI datasets can become increasingly difficult to support when documentation is incomplete or out of date. Understanding relationships, measures and model structure often requires manual review of the report.

Task

Create a reusable utility capable of analysing PBIX files and automatically generating technical documentation.

Action

Developed a Python-based documentation generator using PBIXRay to extract metadata directly from Power BI datasets. The tool automatically exported:

  • Tables
  • Columns
  • Relationships
  • KPIs
  • Model diagrams
  • Unused table analysis
  • Technical documentation files
model = PBIXRay(pbix_path)

rel_df = model.relationships

rel_df.to_csv(
    "relationships.csv",
    index=False
)

The utility also generated Mermaid-compatible relationship diagrams and highlighted potentially unused tables for optimisation review.

Result

Automated Documentation generation
Improved Governance & supportability
Faster Model reviews

The solution reduced the effort required to understand and document Power BI models while improving governance, handovers and opportunities for model optimisation.
