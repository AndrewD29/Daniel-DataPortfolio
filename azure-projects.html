Azure Data Factory Pipeline Optimisation & Power BI Refresh Automation

Azure Data Factory Power BI Azure SQL Key Vault REST API

Situation

An operational Power BI report refreshed every 30 minutes and relied on data loaded through an Azure Data Factory pipeline from the Network Management System (NMS). Dataset refreshes occasionally overlapped with data ingestion and warehouse loading activities, resulting in refresh failures, incomplete reporting data and support investigations.

Task

Modify the existing Azure Data Factory pipeline so Power BI datasets would only refresh after all data ingestion and warehouse loading processes had completed successfully, reducing refresh timing clashes and improving report reliability.

Action

Enhanced the existing Azure Data Factory pipeline by introducing end-to-end orchestration across source ingestion, warehouse loading and Power BI reporting processes. Pipeline execution was logged at both start and end points to improve monitoring and troubleshooting.

After the NMS ingestion process completed successfully, a warehouse loading stored procedure was executed to populate the reporting dimension tables. Only once this process had completed was a Power BI dataset refresh triggered through the Power BI REST API.

Authentication was secured using a Service Principal, with credentials retrieved from Azure Key Vault rather than embedded directly in the pipeline. Failure handling was also introduced to prevent downstream activities running when upstream stages had failed. 

{
    "name": "Refresh_Power BI Report",
    "type": "WebActivity",
    "dependsOn": [
        {
            "activity": "calling usp_load_dim_nms_incident",
            "dependencyConditions": [
                "Succeeded"
            ]
        }
    ]
}

The solution ensured Power BI refreshes were executed only after the latest warehouse data was fully available, providing better alignment between operational and reporting processes.

Result

Reduced Refresh timing clashes
Improved Dataset reliability
Secured Authentication via Key Vault

The enhanced pipeline provided a more reliable reporting process by ensuring Power BI datasets were refreshed using completed and validated warehouse data. This reduced operational support effort, improved confidence in reporting outputs and demonstrated integration across Azure Data Factory, Azure SQL, Azure Key Vault and Power BI.
